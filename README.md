This repository contains the Quarto blog my 2026 fellowship project, Modeling and Visualizing In-Game Win Probability in NCAA Men's Basketball. Using NCAA men's basketball play-by-play data, the project develops statistical models and interactive visualizations to estimate and visualize in-game win probability.
